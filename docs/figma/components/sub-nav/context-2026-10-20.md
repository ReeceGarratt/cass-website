## Notes

- **Changes since 2026-09-29** ([`context.md`](context.md)):
  - **The progress variants are gone.** `02` (`185:2567`), `03` (`185:2580`) and `04` (`188:2593`) no longer exist; only `Default` remains. The growing "progress sweep" underline described in the old notes is no longer in the design.
  - **Active item = Bold + underline; the rest are Regular.** Previously all six links were Bold. In `Default`, "Project Overview" is Bold and the others are Inter Regular 16 / 1.48 / −1.1% (Body Reg). The underline is a 3px **Red** (`#CD2B2B`) rule, 139px wide, spanning exactly "Project Overview" (54.52% → 38.24%), at the bar's bottom edge.
  - **Label case:** "All projects" → "All Projects".
- **Unchanged:** White bar, 80px tall, `26px 110px` padding, 40px gap between section links, 14px gap between arrow and "All Projects", text Purple.
- **The back arrow is still `arrow_upward` rotated** to point left (a Material Symbols Rounded glyph, 21.48 × 22.06, Purple `#4832A1`). Cass's feedback asks for Material `arrow_back`. The rotated glyph has the same shape as `arrow_back`, so the visible difference, if any, is in how the build draws it. Compare the build against `arrow-upward.svg`.
- **Implication for the sticky sub-nav:** with no progress sweep, the active state is per item, so a CSS-only or `aria-current`-based approach is now a closer match to the design than it was. Highlighting the section in view as you scroll still needs a script.
