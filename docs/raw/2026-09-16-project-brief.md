# Project brief (2026-09-16)

> **Raw source: don't edit.** This records the requirements as Reece gave them in a planning chat. If requirements change, add a new dated file; don't change this one.

## Site

A portfolio site for a UX designer (Cass), with:

- a home page
- a number of case studies: write-ups of past projects and the design decisions made
- a contact page
- an about page

## Non-functional requirements

- Must be accessible.
- Must be performant.
- Must support SEO, but SEO isn't part of the first pass.

## Preferences

- Not completely vanilla HTML/CSS/JS. The site should give some exposure to tech outside Reece's usual stack (Eleventy, Astro or similar).
- Reusable components are a plus.
- Tokenised colours and similar values are a big plus.
- It's a small, quick project. Porting to other tech later is acceptable.

## Design and content

- Designs and content for every page exist in Figma. The link will be shared once the tech and a rough plan are agreed.

## Hosting

- Cost and convenience will decide it. There's an existing domain to use.
- Candidates: Cloudflare, or AWS (partly to learn AWS services).
